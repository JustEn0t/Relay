# Безопасность

Проверяемая версия: **2.3.1**. Исправления безопасности вносятся в текущую версию. Проект не имеет независимого сертификата безопасности или внешнего аудита.

## Сообщить об уязвимости

Используй приватное сообщение об уязвимости во вкладке **Security → Report a vulnerability**, если она доступна. Не публикуй токены, сохранённые настройки, приватные идентификаторы или рабочий exploit в общем issue. В обычном issue можно сообщить только общее описание проблемы без секретов и запросить приватный способ связи.

## Что защищает приложение

- Пустые настройки в исходниках и в поставляемом EXE; каждый пользователь вводит свои ключи.
- Windows DPAPI CurrentUser для настроек, резервной копии и очереди удаления.
- API-запросы только по HTTPS к явно разрешённым адресам Twitch/Telegram. Автоматические перенаправления выключены.
- Ключи Twitch передаются в API, а не на URL из метаданных стрима; загрузчик картинок не получает заголовков с токенами.
- Картинки только с CDN Twitch, с ограничениями размера ответа и размеров декодированного изображения.
- Название, категория и история экранируются перед вставкой в HTML-подпись Telegram.
- Сообщения сетевых ошибок не включают URL запроса, токен или необработанный ответ сервера.
- Нет входящего сервера, команд удалённого исполнения, инъекций в игры, обновления исполняемых файлов или телеметрии.
- Установщик не требует администратора, не отключает защиту Windows и не создаёт автозапуск.

## Чего защита не обещает

Программа под той же учётной записью может вызвать DPAPI, а также читать память процесса. Администратор, заражённый ПК, утечка Telegram-токена из другого места и ошибки сторонних сервисов находятся за пределами этой защиты. Используй отдельного Telegram-бота, не передавай свои AppData и обновляй Windows.

Client Secret в личном локальном клиенте не является универсальным секретом разработчика: RELAY не поставляет общий Client Secret. При распространении своей модификации также оставляй поля пустыми.

Сборка неподписанная. SHA-256 позволяет сравнить загрузку с релизом, но не доказывает отсутствие вредоносного кода или любых уязвимостей. Исходники, скрипты сборки и [перечень выполненных проверок](docs/release-checks.md) опубликованы для проверки.
