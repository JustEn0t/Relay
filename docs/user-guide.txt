RELAY 2.3.1 — анонсы Twitch в Telegram

Эту переносимую сборку можно передать другому пользователю.
В переносимом архиве только Relay.exe, эта инструкция и лицензия. Чужие аккаунты и ключи не встроены.
Для запуска распакуй архив и открой Relay.exe на Windows 10/11.
Каждый пользователь подключает своего Telegram-бота и своё приложение Twitch.
Отдельный сервер, платный хостинг и установка Python не нужны.

КАК ПОДКЛЮЧИТЬ
На первом запуске откроется одноимённый раздел приложения с четырьмя шагами.
1. Создай бота у официального @BotFather командой /newbot. Сохрани его токен.
2. Добавь бота администратором Telegram-канала с правом публикации сообщений.
3. На https://dev.twitch.tv/console/apps зарегистрируй своё приложение Twitch.
   Нужны подтверждённая почта и двухфакторная аутентификация.
   Имя приложения должно быть уникальным. Категория — Chat Bot, тип — Confidential.
   OAuth Redirect URL — https://localhost. После создания открой Manage → New Secret.
4. В разделе «Подключения» введи ник Twitch без @, Client ID, Client Secret,
   токен Telegram-бота и @имя Telegram-канала. Для приватного канала нажми «Найти».
   Если канал не найден, опубликуй в нём любой пост после добавления бота и повтори поиск.
   Нажми «Сохранить и проверить». В меню появятся имя и аватар выбранного Twitch-канала.
   Затем открой «Обзор → Включить анонсы».
Официальная документация: https://dev.twitch.tv/docs/authentication/register-app/
Пароль Twitch и ключ трансляции OBS вводить не требуется.
Имя в меню относится к выбранному каналу. RELAY использует публичные данные Twitch.

ВО ВРЕМЯ ЭФИРА
Держи RELAY открытым. Закрытие окна останавливает мониторинг.
При следующем запуске включи анонсы кнопкой. Настройки и состояние сохраняются.
Если канал уже в эфире, анонс может появиться сразу после включения мониторинга.
После подтверждённого завершения эфира RELAY обновит итог и поставит анонс на удаление через 60 минут.
Чтобы удалить пост вовремя, оставь приложение открытым ещё на час после окончания.
Очередь удаления сохраняется с настройками. Если закрыть приложение после постановки в очередь,
просроченное удаление выполнится при следующем запуске. Пауза мониторинга не отключает удаление.
После сетевого сбоя удаление повторится автоматически. Ошибки видны в приложении.
Telegram разрешает удалять сообщения только в течение 48 часов после их отправки.
Это ограничение может помешать автоудалению после очень длинного стрима или долгого выключения ПК.
Проверка — каждые 10 секунд, при сетевых ошибках или лимитах возможны задержки.
Первую минуту после анонса показано «начал стрим» и время старта по МСК.
Через 60 секунд, при ближайшей проверке, статус меняется на «ведёт трансляцию».
Онлайн и длительность обновляются в подписи при изменении данных, проверка каждые 10 секунд.
Картинка обновляется раз в две минуты, при смене названия/игры и при переходе статуса.
Строка статуса расположена по центру нижней части картинки; обычная подпись Telegram остаётся слева.
Если кадр не появился, используется обложка категории.
Один эфир — один пост: начало, изменения, картинка и итог обновляют одно сообщение.
Текущий онлайн показывается только во время эфира. Средний и пиковый онлайн не собираются и не публикуются.
В итогах остаются длительность, основная игра и история изменений.
Это не полная аналитика Twitch. Время истории изменений показывается по МСК.
При неподтверждённой отправке проверь канал перед разрешением повтора, чтобы не создать дубль.

ИНТЕРФЕЙС
Обзор — статус, включение мониторинга, следующая проверка, карточка и активность.
Подключения — свои каналы и ключи. Изменение доступно после остановки мониторинга.
Карточки — предпросмотр начала, текущего эфира и завершения. «Обновить превью» не публикует посты.
Как подключить — пошаговая инструкция с официальными ссылками.
«Отправить тест» публикует отдельное сообщение после подтверждения.

ДАННЫЕ
Настройки: %LOCALAPPDATA%\Relay\settings.protected и зашифрованная резервная копия .bak.
Windows DPAPI защищает их для текущего пользователя Windows.
Программы с доступом к этой учётной записи могут получить сохранённые ключи.
Для обновления старой версии настройки автоматически переносятся из EN0TStreamBot.
Секреты не включены в exe, картинки, исходники и архив для распространения.
Запросы идут по HTTPS к api.telegram.org, id.twitch.tv, api.twitch.tv и static-cdn.jtvnw.net.
Телеметрии и отправки ключей разработчику в коде нет.
Последний публичный кадр стрима хранится локально без шифрования в last-preview.jpg.
Для передачи другим людям используй готовый ZIP, без файлов своей папки AppData.

ИСХОДНИКИ
Desktop.cs + Shell.xaml — интерфейс WPF и управление мониторингом.
Core.cs — API, профиль, шифрование и состояние эфира. Cards.cs — карточки анонсов.
build.ps1 — сборка штатным компилятором .NET Framework. scripts/release.ps1 — установщик и архив из разрешённых файлов.
Assets/cover.png — новая иллюстрация, созданная встроенным генератором изображений.
Assets/cover-prompt.txt — финальный промпт. Все ресурсы встроены в Relay.exe.
