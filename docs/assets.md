# Ресурсы

- `src/Assets/cover.png` — иллюстрация бумажного самолётика, созданная генератором изображений для RELAY. Промпт сохранён в `src/Assets/cover-prompt.txt`. Это не изображение Telegram/Twitch и не их официальный логотип.
- `src/Assets/relay.ico` и `icon.png` — значок RELAY.
- `src/Assets/sample-*.jpg` — локально нарисованные примеры карточок с вымышленным каналом, без снимков реального эфира.
- `assets/cover-*.svg` — фиолетовые баннеры проекта с компактной векторной иконкой самолётика в стиле остальных проектов автора. `assets/relay-icon-*.svg` — отдельные версии иконки. `assets/cover-*.png` и `scripts/render-banners.ps1` — предыдущий вариант с иллюстрацией. `assets/app-preview.png` — снимок интерфейса с пустыми настройками.

В публичной сборке нет фотографий автора, личных скриншотов, обложек игр или загруженных кадров Twitch. Во время использования приложение может загружать публичные материалы выбранного канала и категории из CDN Twitch. Права на них остаются у их владельцев; лицензия репозитория их не охватывает.
