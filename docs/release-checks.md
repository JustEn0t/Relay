# Проверки релиза 2.3.1

Дата: 8 ноября 2026 года. Проверки выполнены локально на Windows x64. Это перечень выполненных проверок, а не независимый аудит, антивирусный сертификат или гарантия отсутствия всех уязвимостей.

## Исходники и границы доступа

- Просмотрены сетевые запросы, сохранение настроек, сообщения об ошибках, запуск внешних ссылок, загрузка изображений и состав ресурсов EXE.
- Для запросов с ключами введена проверка схемы HTTPS, хоста, порта и пути. Для Telegram разрешены только используемые методы Bot API.
- Автоматические HTTP-перенаправления выключены. Проверка TLS-сертификатов Windows не переопределяется.
- Картинки загружаются только из CDN Twitch, без заголовков с ключами. Ограничен размер ответа и декодируемого изображения.
- Настройки по умолчанию пустые. В коде нет сервера разработчика, телеметрии, загрузчика обновлений или удалённых команд.

## Автоматические тесты

`scripts/test.ps1` проходит три набора:

1. Состояния эфира: переход через 60 секунд, обновление онлайна подписью, предел длины Telegram, HTML-экранирование, история, три подтверждения офлайна, защита от повторной неподтверждённой отправки, JPEG и multipart.
2. Хранение и удаление: DPAPI round-trip, отсутствие тестового секрета в открытом виде, атомарная замена и резервная копия; точный часовой срок, отсутствие раннего удаления, перезапуск, повторы после ошибок, сохранение исходного канала/бота, замена токена того же бота, ошибка итогового редактирования и прерванное сохранение.
3. Безопасность запросов: отказ HTTP, похожим доменам, userinfo, нестандартным портам, fragment, localhost, чужим API-методам; пустые настройки и экранирование подписей.

Тесты используют поддельные API и тестовые часы. Реальные посты пользователей не удалялись ради тестов.

## Поиск секретов и состав загрузок

- **Gitleaks 8.30.1** с настройками по умолчанию и полной маскировкой вывода: находок в подготовленном дереве нет. После создания локального коммита отдельно проверяется история Git.
- `scripts/check-release.ps1`: нет файлов настроек, резервных копий, локальных логов, абсолютных пользовательских путей и известных форматов токенов в публичном дереве.
- Отдельной локальной проверкой реальные текущие и старые ключи сравнивались **в памяти** с файлами исходников/загрузок, встроенными ресурсами EXE и распакованным содержимым переносимого ZIP. Совпадений нет. Ключи и значения идентификаторов в отчёт не включены; эта персональная проверка не входит в публичный репозиторий.
- В EXE шесть ожидаемых ресурсов: XAML, иллюстрация, значок и три вымышленных примера карточек. Нет фотографий автора или снимков его эфира. Изображение интерфейса для README сделано с пустыми настройками.
- В переносимом ZIP только `Relay.exe`, `user-guide.txt` и `LICENSE`. В установщик включены только EXE, инструкция и лицензия; штатный uninstaller создаёт Inno Setup.
- Для загрузок опубликован SHA-256. Файлы не подписаны сертификатом издателя.

## Проверка установщика

Проверена настоящая установка в отдельную папку текущего пользователя, без запроса администратора. Установленный EXE побайтно совпал со сборкой. Проверена регистрация удаления в Windows, загрузка WPF с пустыми настройками и штатный uninstaller. После удаления исполняемый файл и регистрация установки отсутствуют. Существующие личные настройки RELAY не изменились.

Компилятор Inno Setup 6.7.4 получен из официального релиза; проверены SHA-256 и действительная Authenticode-подпись издателя. Архив Gitleaks проверен по SHA-256 официального релиза.

## Ограничения

Проверки не доказывают безопасность заражённой Windows, сторонних прокси, API сервисов или будущих модификаций. DPAPI доступен приложениям той же учётной записи; ключи во время работы находятся в памяти. Правила сервисов и ограничения удаления Telegram продолжают действовать. Подробности — в [SECURITY.md](../SECURITY.md) и [PRIVACY.md](../PRIVACY.md).
