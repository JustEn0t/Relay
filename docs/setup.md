# Подключение RELAY

## Установка

Открой `RELAY-Setup-2.3.1.exe` из [официального релиза](https://github.com/JustEn0t/Relay/releases/latest). Стандартная папка: `%LOCALAPPDATA%\Programs\RELAY`. Можно выбрать другую. Администратор не нужен. Ярлык на рабочем столе необязателен. На странице завершения можно запустить RELAY.

Нужны Windows 10/11 x64 и .NET Framework 4.8. Установщик проверяет наличие .NET; не скачивает и не запускает сторонние зависимости автоматически. Сборка без сертификата издателя; сведения о файлах и SHA-256 доступны в релизе.

## Telegram

1. Открой официального [@BotFather](https://t.me/BotFather), выполни `/newbot` и сохрани токен.
2. Добавь нового бота администратором своего Telegram-канала с правом публикации. Не выдавай управление администраторами или другие ненужные права.
3. Введи токен в RELAY в поле «Токен BotFather». Введи `@имя` публичного канала или его числовой ID.
4. Для приватного канала нажми «Найти». Если он не появился, опубликуй любой пост после назначения бота и повтори поиск.

Если у бота уже работает webhook другого приложения, RELAY не удаляет его; автопоиск будет недоступен. Можно указать ID вручную. Для предсказуемой работы используй отдельного бота.

## Twitch

1. Открой [консоль разработчика Twitch](https://dev.twitch.tv/console/apps). Twitch требует подтверждённую почту и двухфакторную аутентификацию.
2. Зарегистрируй приложение с уникальным названием, категорией Chat Bot, типом Confidential и Redirect URL `https://localhost`.
3. В Manage получи Client ID и создай Client Secret.
4. В RELAY введи ник Twitch без `@`, Client ID и Client Secret.

RELAY использует Client Credentials Flow и публичную информацию канала. Пароль Twitch, пользовательская авторизация с доступом к аккаунту, ключ трансляции OBS и права управления Twitch не требуются. Redirect URL нужен для формы регистрации Twitch; приложение не открывает локальный сервер авторизации.

Официальные инструкции: [регистрация](https://dev.twitch.tv/docs/authentication/register-app/), [Client Credentials Flow](https://dev.twitch.tv/docs/authentication/getting-tokens-oauth/#client-credentials-grant-flow).

## Начать работу

Нажми «Сохранить и проверить», затем «Обзор → Включить анонсы». Если эфир уже идёт, RELAY может сразу опубликовать анонс. В меню появятся публичное имя и аватар выбранного канала.

Кнопка «Отправить тест» публикует отдельный тестовый пост после подтверждения. Предпросмотр карточек сообщений не отправляет. Тестовый пост не относится к очереди автоматического удаления анонсов.

## Что происходит с анонсом

- Twitch проверяется каждые 10 секунд, если нет ошибки или ограничения запросов.
- Первую минуту после анонса — «начал стрим» и время начала по МСК.
- Затем — «ведёт трансляцию», текущий онлайн и длительность.
- Картинка обновляется раз в две минуты, при смене игры/названия и статуса. Число зрителей обновляется в подписи.
- Три последовательные проверки без эфира подтверждают его конец. Итог содержит длительность, основную игру и историю. Средний и пиковый онлайн не публикуются.
- Через час после подтверждённого конца этот пост удаляется. Пауза мониторинга не останавливает очередь удаления.

Оставь RELAY открытым во время стрима и ещё час после. После закрытия ничего не проверяется. Сохранённая очередь обрабатывается при следующем запуске; сетевые сбои повторяются с задержкой. Сообщения старше 48 часов Telegram может не разрешить удалить. Очень долгий стрим или долго выключенный ПК могут помешать удалению. При необходимости удали пост вручную.

Если результат отправки неизвестен, приложение просит проверить канал перед повтором: это снижает риск дубликатов.

## Обновление и удаление

Закрой RELAY и установи новую версию поверх прежней. Настройки сохраняются в отдельной папке AppData и автоматически не включают мониторинг при обычном запуске. Переносимая версия использует те же настройки; запускай только один экземпляр.

Удалить приложение можно через «Параметры Windows → Приложения». Настройки сохраняются для переустановки. Полное удаление данных описано в [политике данных](../PRIVACY.md).
