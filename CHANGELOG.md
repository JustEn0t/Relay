# Изменения

## 2.3.1 — 2026-11-08

- Первый публичный релиз RELAY: исходники, инструкция и установщик EXE для текущего пользователя Windows.
- Переносимая ZIP-версия и SHA-256 загрузок.
- Ограничение адресов API и загрузки картинок до разрешённых HTTPS-сервисов.
- Проверки назначения ключей, экранирования подписей, DPAPI, состояний эфира и очереди удаления.
- Страницы с описанием данных, границ защиты и способом сообщения об уязвимости.

Сохранены возможности 2.3: проверка каждые 10 секунд, три состояния карточки, текущий онлайн только во время эфира и удаление анонса через час после подтверждённого конца.
