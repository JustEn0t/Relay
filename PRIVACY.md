# Данные RELAY

Обновлено: 8 ноября 2026 года. Относится к версии 2.3.1 из этого репозитория.

## Где работает приложение

RELAY — локальное приложение Windows. У проекта нет серверной части для хранения пользовательских аккаунтов и нет встроенной телеметрии. Разработчик не получает введённые ключи через приложение.

## Что сохраняется на ПК

В `%LOCALAPPDATA%\Relay\settings.protected` сохраняются настройки подключения, состояние последнего эфира и очередь удаления анонсов. При атомарном обновлении создаётся зашифрованная резервная копия `settings.protected.bak`. Оба файла используют Windows DPAPI CurrentUser.

Содержимое: ник и публичное имя Twitch, URL аватара, Twitch Client ID и Client Secret, токен Telegram-бота, выбранный Telegram-канал, идентификатор сообщения анонса, название/категория/время эфира, текущий онлайн и история изменений. Для удаления старого сообщения очередь может временно хранить прежний токен бота в том же зашифрованном файле. Успешно выполненная задача удаляется из текущей очереди; предыдущее состояние может оставаться в резервной копии. Средний и пиковый онлайн не собираются.

Публичный кадр стрима хранится без шифрования в `last-preview.jpg`, его идентификатор — в `last-preview-stream.txt` той же папки. Это кэш изображения, которое уже доступно через Twitch, а не запись рабочего стола. Картинки категорий и аватар используются в памяти приложения. Журнал активности интерфейса хранится в памяти и не отправляется разработчику.

При обновлении прежнего EN0TStreamBot настройки могут переноситься из `%LOCALAPPDATA%\EN0TStreamBot`. Старая папка автоматически не удаляется.

## Куда идут данные

| Адрес | Назначение и передаваемые данные |
| --- | --- |
| `id.twitch.tv` | Client ID и Client Secret для получения app access token; проверка токена |
| `api.twitch.tv` | App access token, Client ID и запросы публичных данных выбранного канала/категории |
| `static-cdn.jtvnw.net` | Публичный кадр стрима, обложка категории и аватар; без заголовков с токенами Twitch или Telegram |
| `api.telegram.org` | Токен бота, идентификатор канала, опубликованная карточка, подпись и запросы редактирования/удаления |

Соединения идут по HTTPS со стандартной проверкой сертификатов Windows. Системный прокси/VPN влияет на маршрут. Twitch и Telegram обрабатывают запросы согласно собственным правилам; обычные публикации Telegram-канала не являются секретным чатом. Получатели канала видят анонсы.

Кнопки помощи по действию пользователя открывают официальные страницы Twitch и BotFather в браузере. Переходы из README и GitHub Downloads обрабатываются соответствующими сайтами, отдельно от приложения.

## Управление и удаление

Закрытие RELAY останавливает его работу. Удаление программы через Windows убирает приложение и ярлыки, но сохраняет настройки для переустановки. Для полного удаления локальных данных закрой RELAY и вручную удали папку `%LOCALAPPDATA%\Relay` и, если она существует, старую `%LOCALAPPDATA%\EN0TStreamBot`. Это также удалит невыполненную очередь; ранее опубликованные посты останутся в Telegram.

Отзыв токена бота выполняется у BotFather, замена Twitch Client Secret — в Twitch Developer Console. Не прикладывай эти значения, свои настройки или дампы памяти к публичным issues.

## Граница защиты

DPAPI не изолирует секреты от программ под той же учётной записью Windows, администратора или вредоносного ПО. Для API ключи необходимы в памяти запущенного приложения. Раздаваемый EXE не содержит ключей автора, но пользовательские ключи не становятся неуязвимыми после ввода. Используй отдельного бота и выдавай ему только нужные права.
